Stress-test run
===============

Environment: Python 3.13.5, NumPy 2.3.5, pandas 2.2.3, Plotly 6.5.2

Commands:
  python -m compileall -q app src tests
  python -m pytest -q

Result:

Additional property stress test:
  500 randomly generated combinations of capacity, horizon, arrival probability,
  and discrete non-negative fare distributions passed checks for finite/non-negative
  values, monotonicity of value in time and capacity, and nonincreasing marginal
  seat value as capacity increases.
