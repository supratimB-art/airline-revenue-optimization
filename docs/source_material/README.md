# Source-material notes

The model under `src/airline_dp/` is a structured implementation of the finite-horizon seat-inventory Bellman recursion. It is not a line-for-line copy of the original Matplotlib prototype.

The original learning materials include a deterministic/stochastic shortest-path practical, a separate flight-price regression notebook, the Matplotlib prototype, and two academic references. Their substantive role and results are documented in:

- `../learning_journey.md`
- `../flight_price_prediction_notes.md`
- `../references.md`
- `../source_material_inventory.md`

The academic PDF references are linked rather than re-hosted. The flight-price notebook references a local `Flight_Prices.xlsx` workbook that was not provided, so its saved metrics are not independently reproducible from this repository.
