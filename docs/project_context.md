# Project context

## What this project is

An independent summer 2026 learning project built to understand dynamic programming and stochastic optimization by implementing a small airline seat-inventory control model.

## Learning path

- Studied introductory material and lecture slides on dynamic programming and optimal control.
- Read the opening chapter of Dimitri P. Bertsekas's *Dynamic Programming and Optimal Control*.
- Implemented a shortest-path dynamic-programming exercise, including stochastic costs and certainty-equivalence questions.
- Then implemented a finite-horizon airline capacity-control model using backward induction.
- Added tests and an interactive dashboard to explore value functions, bid-price thresholds, and policy comparisons.

## Academic guidance and acknowledgment

Prof. Wang Zizhuo suggested foundational reading and hands-on implementation problems, including shortest paths and airline capacity control, and gave brief feedback on progress and the resulting report. The implementation and experiments in this repository are presented as the student's independent learning work. ## Scope

The baseline model is deliberately small and uses illustrative synthetic fare distributions. It is not calibrated to real airline data and should not be interpreted as a production pricing system or empirical study.
